# Kullanım Kılavuzu

Bu proje, seçilen renge odaklanarak diğer tüm alanları griye çevirir.

## Adımlar
1. MATLAB'ı açın.
2. `src/color_focus_main.m` dosyasını çalıştırın.
3. Açılan pencerede `data/` klasöründen bir görsel seçin.
4. Görsel üzerinde istediğiniz renge tıklayın.
5. Çıktı otomatik olarak `figures/` klasörüne kaydedilir.

## Notlar
- Aynı görsel için farklı renklere tıklarsanız, sonuçlar ayrı dosyalar halinde kaydedilir.
- Çıktı dosya adları giriş görseline göre otomatik oluşturulur.
