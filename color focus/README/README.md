# Color Focus Project 🎨

Bu proje, seçilen renge odaklanarak diğer tüm alanları griye çevirir.  
MATLAB kullanılarak geliştirilmiştir.

## 📂 Klasör Yapısı
- `src/` : MATLAB kodları
- `data/` : Örnek görseller
- `figures/` : Çıktı görselleri
- `docs/` : Ek açıklamalar
- `README.md` : Proje tanıtımı
- `LICENSE` : Lisans bilgisi

## 🚀 Kullanım
1. MATLAB'da `src/color_focus_main.m` dosyasını çalıştırın.
2. `data/` klasöründen bir görsel seçin.
3. Görselde istediğiniz renge tıklayın.
4. Sonuç otomatik olarak `figures/` klasörüne kaydedilir.
